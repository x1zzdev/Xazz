코드 밖에 남지 않는 실행의 근거

Python 저장소 210개를 분석한 연구에서, 결함의 15%는 정적 타입 검사기로 막을 수 있었다. 저자들은 이 값을 하한이라고 밝혔다. — Khan et al., IEEE TSE 2021

코드에 적힌 스키마와 프라이버시

// examples/field_cases/finance_fds/fds_safe.xzz
v txn_by_category = load("data/transactions.csv") :: Transaction
    |> groupBy("merchant_category")
    |> agg([count("is_fraud"), sum("is_fraud")])
    |> orderBy("merchant_category", desc: true);

v amount_by_category = load("data/transactions.csv") :: Transaction
    |> groupBy("merchant_category")
    |> mean("transaction_amount")
    |> withDp(epsilon: 1.0, mechanism: laplace, sensitivity: 1.0)
    |> orderBy("merchant_category");

v fraud_by_band = load("data/transactions.csv") :: Transaction
    |> groupBy("age_band")
    |> agg([count("is_fraud"), sum("is_fraud")])
