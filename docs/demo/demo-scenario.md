# 2차 평가 시연 — 영상 재생 2분 41초 (#154)

라이브 클릭 대신 **녹화 영상**을 재생한다. 영상은 실제 `xazz-server` 응답을 그대로 녹화한 것이고,
장면마다 한국어 자막이 붙어 있다. 발표자는 영상 위에 **말로 해설**만 얹는다.

- 파일: `docs/assets/demo/xazz-demo-ko.webm` (2:41, 무음, 자막 포함)
- 슬라이드 6장이 이 영상의 큐시트다. 7장부터 다시 슬라이드로 돌아온다.
- 재생 도구: 브라우저 새 탭 또는 `mpv`/`VLC`. **전체화면·볼륨 0·자동재생 금지**.

## 발표 30분 전 준비

1. 영상 파일을 **바탕화면이나 발표 폴더**로 복사한다. 저장소 경로에서 직접 열지 않는다.
2. 플레이어에서 열어 **첫 프레임**이 뜨는지 확인한다. 자동재생이 걸려 있으면 끈다.
3. 볼륨은 0으로. 영상에 소리는 없지만 알림음이 섞이지 않게 한다.
4. 재생 → 10초 → 정지 → 다시 재생으로 **위치가 튀지 않는지** 확인한다.
5. 발표 슬라이드(6장)와 플레이어를 **Alt+Tab 한 번**으로 오갈 수 있게 둔다.
6. 재생이 끝나면 **7장으로 돌아온다.** 영상을 끝까지 보지 않고 멈추는 판단은 하지 않는다.

## 큐시트 — 영상 위에 얹는 말

영상은 무음이므로, 아래 문장을 **영상 길이에 맞춰** 말한다. 자막과 같은 내용을 읽지 않는다.
자막은 화면이 설명하고, 발표자는 **왜 그 장면이 중요한지**만 말한다.

| 시각 | 화면 | 말할 것 |
|---|---|---|
| 0:00 | 그래프와 코드가 같이 있는 작업 공간 | “왼쪽 그래프의 노드를 고르면 오른쪽 코드의 해당 줄이 강조됩니다. 같은 파일입니다.” |
| 0:18 | Full Run → Receipt | “실행이 끝나면 서버가 Run ID와 코드 해시를 남깁니다. 프로세스 종료와 파이프라인 성공은 다른 축으로 표시됩니다.” |
| 0:30 | Monitor — 학습 리포트, ε 원장 | “학습 손실과 이번 실행의 ε 사용량입니다. 에폭 진행률은 서버가 스트리밍하지 않아 비워 둡니다 — 추정해서 그리지 않습니다.” |
| 1:05 | 감사 체인 → 변조 | “여기서 감사 레코드 하나를 고칩니다. … 서버가 체인 불일치를 판정하고, 몇 번 레코드인지 짚습니다.” |
| 1:58 | 정책 팩 → 차단 → 보정 | “전화번호를 결과에 남기면 실행 전에 멈춥니다. 사유에 법조항이 붙고, 보정안은 diff로만 제안됩니다.” |
| 2:30 | CSV 업로드 → 스키마 추론 | “CSV를 올리면 서버가 인코딩과 스키마를 추론합니다. 이건 검토용 초안입니다.” |

**말의 밀도**: 6개 장면에 6문장. 영상 2분 41초 동안 계속 말하지 않는다.
각 장면이 끝날 때 **1~2초 침묵**을 둔다. 침묵이 장면을 각인시킨다.

## 재생 중 하지 않는 것

- 마우스를 화면 위에서 움직이지 않는다. 커서가 영상 위에 떠 있으면 산만해진다.
- 자막을 그대로 읽지 않는다. 자막과 발표가 겹치면 정보가 두 배로 늘어난다.
- “여기 보시면”을 반복하지 않는다. 장면당 한 번만.
- 영상이 끝나기 전에 멈추거나 되감지 않는다.

## 실패했을 때

| 증상 | 대응 |
|---|---|
| 영상이 안 열림 | 같은 파일을 `mpv`로 연다. 30초 안에 안 되면 스크린샷 3장(`ide_run_result`, `ide_audit_tamper`, `ide_policy_block_ko`)으로 전환 |
| 화면이 검게만 나옴 | 코덱 문제. 브라우저 새 탭에 파일을 끌어다 놓는다 |
| 소리가 섞임 | 즉시 음소거. 사과하지 않는다 |
| 재생이 중간에 멈춤 | “영상이 멈췄습니다. 마지막 장면은 말로 설명하겠습니다”라고 하고 7장으로 넘어간다 |

영상이 실패해도 **7장(차단·변조 증거)** 은 슬라이드에 있으므로 발표는 성립한다.
그래서 7장을 “영상 백업”으로 만든 것이다.

## 영상 다시 만들기

```bash
# 저장소 루트에서 xazz-server 실행 후
curl -X POST http://127.0.0.1:8005/dp/budget/reset   # ε 예산 초기화
curl -X DELETE http://127.0.0.1:8005/security/policy # 테넌트 팩 제거

cd visual-ide
node scripts/demo.mjs --lang ko --pace story --no-shots --tamper ../audit_log/audit.jsonl
```

- `--pace story`: 결과 화면을 길게 붙잡는 2~3분 컷 (기본값은 1분 요약).
- `--no-shots`: `docs/assets/ide_*.png`를 덮어쓰지 않고 영상만 다시 만든다.
- 재생성 뒤에는 6장의 타임코드를 실제 영상과 맞춘다. (길이가 바뀌면 큐시트도 바뀐다)
