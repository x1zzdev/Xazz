## INTAKE-2026-07-27.02 — 개발 목적

개발 목적 *
Python 기반 AI 파이프라인의 런타임 타입 오류와 언어 간 오버헤드를 줄이기 위해 개발되었습니다. Rust의 강타입 시스템으로 결측치와 타입 오류를 컴파일 단계에서 검증하고, 실시간 보안 무결성 검증 기능을 통합합니다. 단일 DSL 스크립트만으로 데이터 전처리부터 딥러닝 학습까지 엔드투엔드로 제어하는 차세대 오픈소스 AI 개발 플랫폼을 지향합니다. (198/200)

## INTAKE-2026-07-27.03 — 프로젝트 소개

프로젝트 소개 *
Xazz는 Polars 엔진과 Burn 프레임워크를 결합한 Rust 기반 엔드투엔드 DSL 플랫폼입니다. 스크립트 언어의 생산성을 유지하면서도 가능한 경우 제로카피 기반 텐서 변환과 정적 분석 기반 널 안전성을 제공합니다. 또한 대용량 데이터 처리 과정의 비정상적인 입력과 메모리 접근 위험을 최소화하기 위해 데이터 흐름 추적 기반 샌드박스를 구현합니다. 본 플랫폼은 단순한 라이브러리 래퍼가 아니라 파서, AST, 데이터 전처리, 보안 런타임, 딥러닝 컴파일 엔진까지 핵심 툴체인을 직접 설계·구현한 오픈소스 프로젝트입니다. (294/300)

## INTAKE-2026-07-27.04 — 기대 효과

기대 효과 *
Apache Arrow 기반의 효율적인 메모리 레이아웃과 Rust 런타임을 활용하여 기존 Python 중심 데이터 처리 환경 대비 데이터 파이프라인의 실행 성능과 시스템 자원 활용 효율 향상을 지향합니다. 또한 컴파일 단계에서 데이터셋의 결측치와 타입을 정적으로 검사하여 오류를 학습 이전에 조기에 발견함으로써, 대규모 분산 학습 과정에서 발생할 수 있는 불필요한 GPU 자원 낭비를 줄이고 AI 개발의 안정성과 생산성을 향상시킵니다. 아울러 성능 저하를 최소화하는 보안 엔진을 통해 고성능 데이터 신뢰성을 확보하고, 금융·의료 등 민감한 데이터를 다루는 산업에서도 데이터 유출 및 위변조 위험을 최소화하는 AI 학습 인프라 구축을 목표로 합니다. 나아가 선언형 데이터 파이프라인 DSL을 통해 데이터 처리 개발의 진입 장벽을 낮추고, 글로벌 CI/CD 자동화와 체계적인 기여 가이드라인을 기반으로 대한민국 주도의 데이터 엔지니어링 오픈소스 생태계 활성화와 AI 기술 강화에 기여할 것 입니다. (500/500)

## INTAKE-2026-07-27.05 — 기능 범위

[컴파일러 코어] 독자적인 AI 스크립트 언어 파서(Parser)와 내부 구문 트리(AST) 개발
[딥러닝 컴파일] Rust 기반 고성능 AI 프레임워크인 Burn을 연동하여, 코드가 내부적으로 제로카피 텐서 연산 및 딥러닝 학습 레이어로 전환되도록 컴파일 계층 구현
[데이터 가속 엔진] Rust 환경의 Polars 엔진을 융합하여 사용자가 요청한 전처리 명령을 초고속 LazyFrame 연산 그래프로 변환하고 처리하는 파이프라인 구축
[정적 가드레일] 사용자가 작성한 코드가 실행되기 직전 단계에서 개인정보 유출이나 보안 컴플라이언스 위반을 실시간으로 탐지하고 차단하는 Policy-as-Code 통제 계층 구현
[프라이버시 R&D] 데이터에 통계적 노이즈를 주입해 수학적 안전성을 보장하는 차등 프라이버시(DP) 알고리즘을 파이썬/러스트 환경에서 연구 및 검증
[내장형 sLM 엔진] 외부 유출이 없는 온프레미스 sLM을 탑재하여, 보안 정책에 차단된 코드를 안전하게 자동 보정하고 개발자에게 위반 사유 및 코드 분석 리포트를 제공하는 지능형 AI 어시스턴트 모듈 구축
[비주얼 콘솔 UI] React와 @xyflow/react를 활용해 데이터 전처리 및 딥러닝 레이어가 컴파일되는 전체 파이프라인 흐름을 눈으로 보여주는 웹 IDE 화면 개발
[실시간 모니터링] 차등 프라이버시(DP)의 보안 예산(Privacy Budget) 소모 상태와 연산 자원 효율성을 직관적인 차트로 보여주는 통계 대시보드 구축
[신뢰성 인프라] 모든 연산 이력을 영구 보존하는 SHA-256 감사 로그 시스템을 설계하고, 글로벌 오픈소스 수준의 GitHub Actions 기반 CI/CD 및 자동화 테스트 환경 구축

## INTAKE-2026-07-27.07 — UI/UX 기여 목표

지금 내가 여기 UI/UX 담당 팀원으로 들어와 있는데, 일단 깃 클론해서 현상태 분석하고 우리에게 있는 UI/UX 관련 자산을 검토하여 어떤 접근을 할 수 있을지 설계해보자. 그냥 코드부터 짜는 게 아니라 실제 디자이너처럼 사용자의 입장에서 어떤 가치를 원할지 고민해보고 즉시성과 효능감 등을 느낄 수 있게 처음 랜딩페이지부터 도구 사용 경험까지 이어지는 흐름을 먼저 구조화한 후에 그에 맞는 UI를 피그마로 구현해보고, 그 과정에서 우리가 위키에 수집해놓고 하네스에 적용한 많은 ui/ux관련 팁과 스킬들을 사용해서 디자이너 못지않은 결과를 내놓는 게 내 목표야. 그리고 제대로 이뤄진다면 이 경험을 토대로 디자인 부분의 하네스를 보강할 예정이므로 내 지시를 철저히 지켜서 따라와줘야 해.
