# Xazz prototype asset ledger

승인된 `spec/SPEC.yaml` 0.1.1의 8-state clickable prototype을 위한 자산
판정 기록이다. 경로는 `Xazz/` 저장소 루트를 기준으로 하며, 형제 저장소는
`../x1zzLang-visual-ide-openssl/`로 표기한다.

## 판정 기준

| 판정 | 의미 |
|---|---|
| **재사용** | 로컬 프로토타입에 코드 또는 명세를 가져올 수 있다. 아래 제한 조건은 반드시 적용한다. |
| **개념 재사용** | 정보 구조나 interaction pattern만 참고한다. 기존 시각 스타일·카피·상태 의미를 복제하지 않는다. |
| **폐기** | 승인된 프로토타입에 복사·임베드·링크하지 않는다. |

`spec/SPEC.yaml`, `design-system/xazz/MASTER.md`, 그리고
`design-system/xazz/pages/workspace.md`가 이 문서보다 우선하는 source of truth다.

## Local-only asset contract

- prototype data, code, chart payload, error payload, readiness, receipt는 repository에
  포함된 synthetic fixture에서만 읽는다.
- font는 system stack, icon은 locally bundled Lucide, chart는 local SVG component를
  사용한다.
- screenshot은 product runtime asset으로 임베드하지 않는다.
- unavailable field는 `Not available`, future capability는
  `Demo`/`Research`/`Planned`로 표시하며 관측값을 발명하지 않는다.
- process state, pipeline verdict, control state, integrity state, artifact outcome은
  서로 다른 field/component로 유지한다.
